# Student Marks Report

## 📌 Project Description
This Python project generates a report of student marks using predefined student data. It calculates each student's total marks and average score, assigns grades, calculates the class average, counts students scoring above the class average, and identifies the topper.

## ✨ Features
- Calculates total marks for each student.
- Calculates the average marks across three subjects.
- Assigns grades based on average marks:
  - **A:** Average ≥ 90
  - **B:** Average ≥ 80
  - **C:** Average ≥ 70
  - **D:** Average ≥ 60
  - **F:** Average < 60
- Calculates the overall class average.
- Counts students whose average is above the class average.
- Identifies the student with the highest average marks.
- Displays the results in the console.

## 🛠️ Technologies Used
- Python 3

## ▶️ How to Run

1. Make sure Python 3 is installed on your system.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python messy.py
```
